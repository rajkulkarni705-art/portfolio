GitHub Pages Deployment Guide

Step 1: Save file

Save this application code in a file named index.html inside your local project directory.

Step 2: Initialize Git & Push to GitHub

git init

git add index.html

git commit -m "Initial portfolio release"

git branch -M main

git remote add origin https://github.com/YOUR_USERNAME/portfolio.git

git push -u origin main

Step 3: Enable Pages

Go to your GitHub repository: Settings → Pages → Source select main branch and save. Your site will be published live at https://username.github.io/portfolio!
